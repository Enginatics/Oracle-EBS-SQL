# OPM Batch Lot Genealogy – Oracle EBS SQL Report

**Oracle E-Business Suite** SQL report from the [Enginatics Library](https://www.enginatics.com/reports/opm-batch-lot-genealogy/) powered by [Blitz Report™](https://www.enginatics.com/blitz-report/).

## Overview
Oracle Process Manufacturing (OPM) batch lot genealogy: the parent-to-child lot relationships (which ingredient lots produced which product lots), enriched with each lot's material status, grade, origination and expiration dates. Supports recall, quality and where-used lot traceability.
