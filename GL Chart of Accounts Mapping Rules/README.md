# GL Chart of Accounts Mapping Rules – Oracle EBS SQL Report

**Oracle E-Business Suite** SQL report from the [Enginatics Library](https://www.enginatics.com/reports/gl-chart-of-accounts-mapping-rules(1)/) powered by [Blitz Report™](https://www.enginatics.com/blitz-report/).

## Overview
Lists the segment mapping rules and code combination mappings defined for a Global Consolidation System (GCS) chart of accounts mapping. Converted from the Oracle BI Publisher report 'Chart of Accounts - Mapping Rules (XML)' (GLXCOCRR_XML).
